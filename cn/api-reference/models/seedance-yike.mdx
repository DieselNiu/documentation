---
title: "Seedance 视频"
api: "POST /api/v1/task/submit"
---

使用 MaxAPI 的 [API 密钥](/cn/api-reference/authentication)提交 Seedance 任务。各档按输出时长计费。

| 模型 | API 模型 ID | 输出秒数 | 图片上限 | 720p | 1080p |
| --- | --- | --- | --- | --- | --- |
| Seedance 2.5 | `seedance-2.5` | 4–30 | 30 | $0.225/s | $0.550/s |
| Seedance 2.0 | `seedance-2.0-yike` | 4–15 | 9 | $0.147/s | $0.365/s |
| Seedance 2.0 Mini | `seedance-2.0-mini` | 4–15 | 9 | $0.071/s | $0.141/s |

在 `input` 传入必填的 `prompt` 和可选的 `duration`、`resolution`、`ratio`、`audio`、`mode`、`imageUrls`。默认输出为 5 秒、720p。`ratio` 支持 `16:9`、`9:16`、`4:3`、`3:4`、`1:1`、`21:9`、`adaptive`。

- `text-to-video` 使用提示词。
- `image-to-video` 使用一张起始图。
- `first-last-frame` 使用首尾各一张图。
- `reference-to-video` 使用一张或多张参考图。

图片请使用外部可访问的 HTTP(S) URL。省略 `mode` 时，系统按零张、单张、多张分别推断文生视频、图生视频和参考图模式。当前支持文字和图片输入。

按秒计算总价后向上取整至整积分，1 积分等于 $0.01。比如 Seedance 2.5 的 4 秒 720p 请求扣 90 积分。

```json
{
  "model": "seedance-2.0-yike",
  "input": {
    "prompt": "一只纸船在晨光下缓慢漂浮，镜头固定",
    "duration": 4,
    "resolution": "720p"
  }
}
```

用返回的 `data.taskId` [查询任务](/cn/api-reference/query-task)或接收 [Webhook](/cn/api-reference/webhook)。
