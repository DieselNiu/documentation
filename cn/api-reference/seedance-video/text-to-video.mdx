---
title: "Text to Video"
api: "POST /api/v1/task/submit"
description: "Seedance 文生视频 — 通过文字描述生成视频"
---

使用 Seedance 模型，通过纯文字 prompt 生成视频。不传 `mediaUrls`（或 `imageUrls`）即为纯文生视频模式。

<Warning>
  Seedance 视频生成耗时可能在 **2 分钟到 4 小时**之间，具体取决于上游官方接口的排队情况。使用该模型时，建议你**务必配置 `callBackUrl`**，这样结果一旦生成完成即可及时回调通知。**不建议**持续轮询 [Query Task](/api-reference/query-task) 接口。
</Warning>

### 可用模型

`seedance-2.0` · `seedance-2.0-fast` · `seedance-1.5-pro`

<ParamField body="model" type="string" required>
  模型名称，如 `seedance-2.0`、`seedance-2.0-fast`、`seedance-1.5-pro`。
</ParamField>

<ParamField body="callBackUrl" type="string">
  Webhook 回调地址。强烈建议用于 Seedance 视频任务，因为生成耗时可能在 2 分钟到 4 小时之间，取决于上游官方接口排队情况。
</ParamField>

<ParamField body="input" type="object" required>
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      提示词，描述你想生成的视频内容。
    </ParamField>
    <ParamField body="ratio" type="string">
      视频比例。可选值：`1:1`、`4:3`、`3:4`、`16:9`、`9:16`。
    </ParamField>
    <ParamField body="resolution" type="string">
      视频分辨率。可选值：`480p`、`720p`、`1080p`。
    </ParamField>
    <ParamField body="duration" type="integer">
      视频时长（秒）。`seedance-2.0` 和 `seedance-2.0-fast` 支持 `4`–`15` 秒；`seedance-1.5-pro` 支持 `5` 或 `10`。
    </ParamField>
    <ParamField body="fallback" type="boolean" default="true">
      Seedance 2.0 模型失败后是否自动降级到 `seedance-1.5-pro`。默认 `true`。设为 `false` 则禁止降级，直接返回原始错误。仅对 `seedance-2.0` 和 `seedance-2.0-fast` 生效，`seedance-1.5-pro` 忽略此字段。
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.maxapi.io/api/v1/task/submit \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "seedance-2.0",
  "callBackUrl": "https://example.com/webhook",
  "input": {
    "prompt": "一条河流穿过秋天的森林，航拍视角",
    "ratio": "16:9",
    "resolution": "1080p",
    "duration": 5,
    "fallback": true
  }
}'
```
</RequestExample>

<ResponseExample>
```json 200 提交成功
{
  "code": 0,
  "msg": "ok",
  "data": {
    "taskId": "790758ee-3675-48fa-a9af-33d33cf84e71"
  }
}
```
</ResponseExample>

## 查询结果

通过 [Query Task](/api-reference/query-task) 接口或 Webhook 获取生成结果：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "taskId": "790758ee-3675-48fa-a9af-33d33cf84e71",
    "status": "SUCCESS",
    "input": {
      "model": "seedance-2.0",
      "prompt": "一条河流穿过秋天的森林，航拍视角",
      "ratio": "16:9",
      "resolution": "1080p",
      "duration": 5,
      "fallback": true
    },
    "result": {
      "type": "video",
      "urls": [
        "https://example.com/output/video-example.mp4"
      ]
    },
    "created_at": "2026-02-10T22:05:27.378310Z",
    "updated_at": "2026-02-10T22:08:11.389509Z"
  }
}
```

<Note>
  视频生成通常返回 1 个视频 URL。`result` 仅在 `status` 为 `SUCCESS` 时有值。
</Note>
