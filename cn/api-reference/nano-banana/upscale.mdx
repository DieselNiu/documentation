---
title: "图片放大"
api: "POST /api/v1/task/submit"
description: "Nano Banana Upscale — 基于 Gemini 3.0 Pro upsampler 的独立 2K / 4K 图片放大接口"
---

独立的图片放大接口。传入任意图片 URL 和目标分辨率，返回该图片的 2K 或 4K 高清版本。**没有 prompt，也不做生成式编辑**，只做分辨率放大。

### 可用模型

`nano-banana-upscale`

<ParamField body="model" type="string" required>
  必须为 `nano-banana-upscale`。
</ParamField>

<ParamField body="callBackUrl" type="string">
  Webhook 回调地址。
</ParamField>

<ParamField body="input" type="object" required>
  <Expandable title="properties" defaultOpen>
    <ParamField body="imageUrls" type="array" required>
      包含**恰好 1 张**公网可访问图片 URL 的数组（HTTPS，JPEG / PNG / WebP）。
    </ParamField>
    <ParamField body="resolution" type="string" required>
      目标分辨率。可选值：`2k`、`4k`。**不支持 `1k`**——如需 1K 输出，请使用普通 Nano Banana 系列模型。
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```bash 2K 放大
curl --request POST \
  --url https://api.maxapi.io/api/v1/task/submit \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "nano-banana-upscale",
  "callBackUrl": "https://example.com/webhook",
  "input": {
    "imageUrls": ["https://example.com/source.jpg"],
    "resolution": "2k"
  }
}'
```

```bash 4K 放大
curl --request POST \
  --url https://api.maxapi.io/api/v1/task/submit \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "nano-banana-upscale",
  "input": {
    "imageUrls": ["https://example.com/source.jpg"],
    "resolution": "4k"
  }
}'
```
</RequestExample>

<ResponseExample>
```json 200 提交成功
{
  "code": 0,
  "msg": "ok",
  "data": {
    "taskId": "c3d4e5f6-a7b8-9012-cdef-234567890abc"
  }
}
```
</ResponseExample>

```json
      "resolution": "2k"
    },
    "result": {
      "type": "image",
      "urls": [
        "https://example.com/output/image-c3d4e5f6.png"
      ]
    },
    "created_at": "2026-02-12T12:00:00.000000Z",
    "updated_at": "2026-02-12T12:01:30.000000Z"
  }

```

<Warning>
  **输入图片要求：**
  - 格式：JPEG、PNG、WebP
  - 必须是公网可访问的 HTTPS 地址
  - 建议大小：< 10MB
  - 放大通常需要 30s – 2min
</Warning>
