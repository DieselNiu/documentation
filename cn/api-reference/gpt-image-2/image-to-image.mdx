---
title: "图生图"
api: "POST /api/v1/task/submit"
description: "GPT Image 2 图生图 —— 基于参考图与提示词编辑图像"
---

使用 GPT Image 2 编辑现有图像。Max API 会拉取每个 `imageUrls` 并以 `multipart/form-data` 转发到上游 `/v1/images/edits`。

### 可用模型

`gpt-image-2/image-to-image`

### 价格

- **$0.006 / 张**（固定）

<ParamField body="model" type="string" required>
  `gpt-image-2/image-to-image`
</ParamField>

<ParamField body="callBackUrl" type="string">
  Webhook 回调地址。
</ParamField>

<ParamField body="input" type="object" required>
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      描述要应用的编辑效果。
    </ParamField>
    <ParamField body="imageUrls" type="string[]" required>
      可公网访问的参考图 HTTPS URL。上游 `/v1/images/edits` 只接受 **1 张**，多传的会被丢弃。WebP 会自动转码为 JPEG。
    </ParamField>
    <ParamField body="n" type="integer">
      输出变体数量。范围 `1-4`，默认 `1`。
    </ParamField>
    <ParamField body="model" type="string">
      上游模型变体。可选 `gpt-image-2`（默认）或 `gpt-image-1`。
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```bash default
curl --request POST \
  --url https://api.maxapi.io/api/v1/task/submit \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "gpt-image-2/image-to-image",
  "callBackUrl": "https://example.com/webhook",
  "input": {
    "prompt": "酷酷的风格",
    "imageUrls": ["https://example.com/source.jpg"],
    "n": 1
  }
}'
```
</RequestExample>

<ResponseExample>
```json 200 提交成功
{
  "code": 0,
  "msg": "ok",
  "data": {
    "taskId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  }
}
```
</ResponseExample>

## 获取结果

通过 [Query Task](/cn/api-reference/query-task) 或 Webhook 获取结果。

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "taskId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "status": "SUCCESS",
    "input": {
      "model": "gpt-image-2/image-to-image",
      "prompt": "酷酷的风格"
    },
    "result": {
      "type": "image",
      "urls": ["https://cdn.maxapi.io/images/.../image-0.png"]
    }
  }
}
```
