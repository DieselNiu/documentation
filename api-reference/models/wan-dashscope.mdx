## Video inputs

`input.prompt` is required. The output defaults to 5 seconds at 720p. Pass images via `input.imageUrls`. If `mode` is omitted, the image count determines the mode. For first and last frames, send two images in order with `mode: "first-last-frame"`.

- `wan-3.0` and `wan-3.0-prime` support text-to-video, a single starting image, first and last frames, or up to 10 reference images. Set `audio: false` to disable generated audio. Aspect ratios are `adaptive`, `16:9`, `9:16`, `4:3`, `3:4`, and `1:1`.
- `wan-2.7` supports text, a single starting image, or first and last frames. Standard `wan-2.6` and `wan-2.5` support text or a single starting image. `wan-2.6-flash` requires one starting image. These four versions accept one optional driving audio URL in `audioUrls`. For silent Flash output, use `audio: false` and omit `audioUrls`.
- Wan 2.x video accepts `16:9`, `9:16`, `4:3`, `3:4`, and `1:1`. On `wan-2.5`, 480p text-to-video accepts `16:9`, `9:16`, and `1:1`.

## Video pricing (USD per second)

| Model ID | Duration (seconds) | 480p | 720p | 1080p |
| --- | --- | --- | --- | --- |
| `wan-3.0` | 2–30 | $0.0575 | $0.115 | $0.23 |
| `wan-3.0-prime` | 2–30 | $0.0782 | $0.161 | $0.322 |
| `wan-2.7` | 2–15 | — | $0.115 | $0.1725 |
| `wan-2.6` | 5, 10, 15 | — | $0.115 | $0.1725 |
| `wan-2.6-flash` | 5, 10, 15 | — | $0.0575 | $0.08625 |
| `wan-2.5` | 5, 10 | $0.0575 | $0.115 | $0.1725 |
| `wan-2.6-flash` (silent) | 5, 10, 15 | — | $0.02875 | $0.043125 |

Multiply the rate by the output duration and round the total up to a whole credit. One credit is $0.01. For example, a five-second 720p clip from `wan-3.0` costs 58 credits.

## Images

`input.prompt` is required. Both versions accept up to nine optional reference images. Optional fields are `imageUrls`, `resolution`, `ratio`, and `seed`. Each request returns one image.

| Model ID | Resolutions | Credits charged |
| --- | --- | --- |
| `wan-2.7-image` | 1k / 2k | 4 credits per image |
| `wan-2.7-image-pro` | 1k / 2k / 4k (text-to-image only) | 9 credits per image |

## Example request

```json
{
  "model": "wan-3.0",
  "input": {
    "prompt": "A paper boat drifts across a quiet pond at sunrise.",
    "duration": 5,
    "resolution": "720p",
    "ratio": "16:9"
  }
}
```
