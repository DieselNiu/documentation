## Model IDs and parameter coverage

| Model ID | Accepted input fields |
| --- | --- |
| `seedream-5-5` | `prompt`, `imageUrls`, `ratio`, `resolution`, `n`, `output_format`, `background`, `watermark`, `nsfw_check`, `optimize_prompt_options` |

Send `model` and `input` in the JSON body. `input.prompt` is required. Image-to-image and image-to-video IDs require reference images. Use only the input fields listed for your selected ID; a family-wide table does not mean every variant accepts every field.

## Parameters

| Field | Type | Values / limits | Description |
| --- | --- | --- | --- |
| `model` | string | seedream-5-5 | The model to run. |
| `input.prompt` | string | text | What to generate. Describe the subject, the action and the style. |
| `input.imageUrls` | string[] | 0–10 HTTP(S) URLs | Optional. Every reference is billed, including the first. |
| `input.ratio` | string | 1:1 &#124; 4:3 &#124; 3:4 &#124; 16:9 &#124; 9:16 &#124; 3:2 &#124; 2:3 &#124; 21:9 | Optional aspect ratio. Omit to use the size tier directly. |
| `input.resolution` | string | 1k &#124; 1.5k &#124; 2k | Default 2k. 1k and 1.5k share the lower output price. |
| `input.n` | integer | 1 | Only one output per request; default 1. |
| `input.output_format` | string | png &#124; jpeg | Default png. Transparent output requires png. |
| `input.background` | string | auto &#124; transparent &#124; opaque | Optional, default auto. Transparent PNG works with or without references. |
| `input.watermark` | boolean | true &#124; false | Optional upstream AI watermark; default false. |
| `input.nsfw_check` | boolean | false | Optional. Omit or send false; separately billed upstream moderation is unavailable. |
| `input.optimize_prompt_options` | object | `{"mode":"standard"}` | Optional. Standard optimization is always enabled; it cannot be disabled. |
| `callBackUrl` | string | URL | Optional webhook called when the task finishes. |

Use public HTTP(S) media URLs that the generation service can fetch. Replace all example media URLs with your own files. Mode-specific requirements and provider limits below still apply after local validation.

## Supported scope and limits

- One output per request (n=1). Up to 10 HTTP(S) reference images.
- Layer decomposition, OCR, custom pixel sizes, data URIs and 4K are not exposed by MaxAPI; unsupported fields are rejected.
- Standard prompt optimization is always enabled upstream. Transparent output requires PNG.
- The total price is rounded once per request to the nearest $0.000001. Default output is 2K PNG.

Add the output-image price and $0.00736 for each reference image, including the first. The lower output tier covers 1K and 1.5K; the default is 2K.

The total output and reference-image price is rounded once to the nearest microdollar ($0.000001). Credits = microdollars / 10000, preserving four credit decimal places. One credit is $0.01. The following examples show the actual debit.

## Submit and query

```bash
curl https://maxapi.io/api/v1/task/submit \
  -H "Authorization: Bearer $MAXAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedream-5-5",
    "input": {
      "prompt": "A colorful clay miniature cafe, warm sunlight and a sign reading MORNING RITUAL.",
      "resolution": "2k",
      "ratio": "1:1",
      "background": "auto",
      "output_format": "png"
    }
  }'

# -> { "code": 0, "data": { "taskId": "..." } }
curl https://maxapi.io/api/v1/task/$TASK_ID \
  -H "Authorization: Bearer $MAXAPI_API_KEY"
```

A successful submission returns `data.taskId`; it does not mean generation has completed. Poll [Query Task](/api-reference/query-task) or use a [Webhook](/api-reference/webhook). Stop polling on `SUCCESS`, `FAILURE`, `TIMEOUT` or `CANCELLED`. A pending or uncertain submission must not be blindly resubmitted.

## Billing and model notes

### How much does the Seedream 5.5 API cost?

From $0.0184/image. For example: 1K, no references costs $0.018400. See the pricing table above for every variant and resolution.

### What resolutions does Seedream 5.5 support?

1k, 1.5k, 2k. A request takes up to 10 input images. It returns one image.

### How is the final credit charge calculated?

The total output and reference-image price is rounded once to the nearest $0.000001 and debited using fractional credits (1 credit = $0.01). It is not rounded up to whole credits.

### Are reference images free?

The per-reference price in the pricing table applies to every reference image, including the first.

### Can I split an image into layers?

Not through MaxAPI yet. Layer decomposition and OCR parameters are rejected, not silently ignored.

### Am I charged if a task fails?

Confirmed failures, including content moderation rejections, are refunded in full. For a pending submission or a request timeout, check the task status before retrying.
