---
title: "Seedance Video"
api: "POST /api/v1/task/submit"
---

Use a MaxAPI [API key](/api-reference/authentication) to submit a Seedance task. Billing depends on output duration and resolution.

| Model | API model ID | Output seconds | Max images | 720p | 1080p |
| --- | --- | --- | --- | --- | --- |
| Seedance 2.5 | `seedance-2.5` | 4–30 | 30 | $0.225/s | $0.550/s |
| Seedance 2.0 | `seedance-2.0-yike` | 4–15 | 9 | $0.147/s | $0.365/s |
| Seedance 2.0 Mini | `seedance-2.0-mini` | 4–15 | 9 | $0.071/s | $0.141/s |

Send a required `prompt` and optional `duration`, `resolution`, `ratio`, `audio`, `mode`, and `imageUrls` in `input`. The defaults are 5 seconds and 720p. The available ratios are `16:9`, `9:16`, `4:3`, `3:4`, `1:1`, `21:9`, and `adaptive`.

- `text-to-video` uses the prompt.
- `image-to-video` uses one opening image.
- `first-last-frame` uses one opening image and one closing image.
- `reference-to-video` uses one or more reference images.

Use publicly accessible HTTP(S) image URLs. When `mode` is omitted, zero, one, or multiple images select text, image, or reference mode respectively. This release supports text and image inputs.

Multiply the rate by duration and round up to a whole credit. One credit equals $0.01. A 4-second 720p Seedance 2.5 task costs 90 credits.

```json
{
  "model": "seedance-2.0-yike",
  "input": {
    "prompt": "A paper boat drifts slowly in morning light, with a steady camera",
    "duration": 4,
    "resolution": "720p"
  }
}
```

Use the returned `data.taskId` to [query the task](/api-reference/query-task) or receive a [webhook](/api-reference/webhook).
