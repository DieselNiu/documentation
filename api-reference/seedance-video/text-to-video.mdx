---
title: "Text to Video"
api: "POST /api/v1/task/submit"
description: "Seedance Text-to-Video — Generate videos from text descriptions"
---

Use Seedance models to generate videos from a text prompt. Omitting `mediaUrls` (or `imageUrls`) activates pure text-to-video mode.

<Warning>
  Seedance video generation can take anywhere from **2 minutes to 4 hours**, depending on the upstream provider's queue. You should **always configure `callBackUrl`** when using this model so the result can be delivered as soon as it is ready. Continuous polling of the [Query Task](/api-reference/query-task) endpoint is **not recommended**.
</Warning>

### Available Models

`seedance-2.0` · `seedance-2.0-fast` · `seedance-1.5-pro`

<ParamField body="model" type="string" required>
  Model name, e.g. `seedance-2.0`, `seedance-2.0-fast`, `seedance-1.5-pro`.
</ParamField>

<ParamField body="callBackUrl" type="string">
  Webhook callback URL. Strongly recommended for Seedance video tasks because generation latency may range from 2 minutes to 4 hours depending on the upstream queue.
</ParamField>

<ParamField body="input" type="object" required>
  <Expandable title="properties" defaultOpen>
    <ParamField body="prompt" type="string" required>
      Prompt describing the video you want to generate.
    </ParamField>
    <ParamField body="ratio" type="string">
      Video aspect ratio. Options: `1:1`, `4:3`, `3:4`, `16:9`, `9:16`.
    </ParamField>
    <ParamField body="resolution" type="string">
      Video resolution. Options: `480p`, `720p`, `1080p`.
    </ParamField>
    <ParamField body="duration" type="integer">
      Video duration in seconds. `seedance-2.0` and `seedance-2.0-fast` support `4`–`15` seconds; `seedance-1.5-pro` supports `5` or `10`.
    </ParamField>
    <ParamField body="fallback" type="boolean" default="true">
      Whether to automatically fall back to `seedance-1.5-pro` when a Seedance 2.0 model fails. Defaults to `true`. Set to `false` to disable fallback and return the original error directly. Only applies to `seedance-2.0` and `seedance-2.0-fast`; ignored by `seedance-1.5-pro`.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.maxapi.io/api/v1/task/submit \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "seedance-2.0",
  "callBackUrl": "https://example.com/webhook",
  "input": {
    "prompt": "A river flowing through autumn forest, aerial view",
    "ratio": "16:9",
    "resolution": "1080p",
    "duration": 5,
    "fallback": true
  }
}'
```
</RequestExample>

<ResponseExample>
```json 200 Submitted successfully
{
  "code": 0,
  "msg": "ok",
  "data": {
    "taskId": "790758ee-3675-48fa-a9af-33d33cf84e71"
  }
}
```
</ResponseExample>

## Query Result

Retrieve the generation result via the [Query Task](/api-reference/query-task) endpoint or Webhook:

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "taskId": "790758ee-3675-48fa-a9af-33d33cf84e71",
    "status": "SUCCESS",
    "input": {
      "model": "seedance-2.0",
      "prompt": "A river flowing through autumn forest, aerial view",
      "ratio": "16:9",
      "resolution": "1080p",
      "duration": 5,
      "fallback": true
    },
    "result": {
      "type": "video",
      "urls": [
        "https://example.com/output/video-example.mp4"
      ]
    },
    "created_at": "2026-02-10T22:05:27.378310Z",
    "updated_at": "2026-02-10T22:08:11.389509Z"
  }
}
```

<Note>
  Video generation typically returns 1 video URL. `result` is only populated when `status` is `SUCCESS`.
</Note>
