---
title: "Image Upscale"
api: "POST /api/v1/task/submit"
description: "Nano Banana Upscale — Standalone 2K / 4K image upscale powered by the Gemini 3.0 Pro upsampler"
---

Standalone image upscale endpoint. Pass any image URL and a target resolution; receive a 2K or 4K version of the same image. There is no prompt and no generative editing — only resolution upsampling.

### Available Models

`nano-banana-upscale`

<ParamField body="model" type="string" required>
  Must be `nano-banana-upscale`.
</ParamField>

<ParamField body="callBackUrl" type="string">
  Webhook callback URL.
</ParamField>

<ParamField body="input" type="object" required>
  <Expandable title="properties" defaultOpen>
    <ParamField body="imageUrls" type="array" required>
      Array containing **exactly 1** publicly accessible image URL (HTTPS, JPEG / PNG / WebP).
    </ParamField>
    <ParamField body="resolution" type="string" required>
      Target resolution. Options: `2k`, `4k`. There is no `1k` mode — for 1K output use the regular Nano Banana models.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```bash 2K Upscale
curl --request POST \
  --url https://api.maxapi.io/api/v1/task/submit \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "nano-banana-upscale",
  "callBackUrl": "https://example.com/webhook",
  "input": {
    "imageUrls": ["https://example.com/source.jpg"],
    "resolution": "2k"
  }
}'
```

```bash 4K Upscale
curl --request POST \
  --url https://api.maxapi.io/api/v1/task/submit \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "nano-banana-upscale",
  "input": {
    "imageUrls": ["https://example.com/source.jpg"],
    "resolution": "4k"
  }
}'
```
</RequestExample>

<Warning>
  **Input Image Requirements:**
  - Formats: JPEG, PNG, WebP
  - Must be publicly accessible HTTPS URL
  - Recommended size: < 10MB
  - Upscaling typically takes 30s – 2min
</Warning>
